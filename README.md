# 💰 حساب‌یار — دفتر دخل و خرج شخصی

دفترچهٔ دخل و خرج، ساده و شفاف. سبز یعنی دخل، قرمز یعنی خرج — با ثبت سریع، ویرایش و حذف، نمودار ترکیب هزینه‌ها، تاریخ شمسی و حالت روز و شب. همه‌چیز در یک صفحه، بدون ثبت‌نام و بدون سرور.

> نسخهٔ حاضر یک **خروجی کاملاً استاتیک** است و روی GitHub Pages منتشر می‌شود. داده‌های شما فقط در `localStorage` مرورگر خودتان ذخیره می‌شود و جایی ارسال نمی‌شود.

## ✨ امکانات

- ثبت سریع هزینه (قرمز) و درآمد (سبز) با دسته‌بندی و تاریخ
- ویرایش و حذف تراکنش‌ها + فیلتر «همه / درآمدها / هزینه‌ها»
- پنل موجودی کل + جمع درآمد و هزینه با اعداد متحرک
- نمودار دونات ترکیب هزینه‌ها (SVG دست‌ساز، بدون کتابخانهٔ نمودار)
- تاریخ شمسی و ارقام فارسی در کل رابط
- حالت روز و شب با یادآوری انتخاب
- پس‌زمینهٔ سینمایی «موج برنز» با WebGL خام + لودر شمارنده و کرسر سفارشی دسکتاپ
- کاملاً ریسپانسیو و سازگار با `prefers-reduced-motion`

## 🧰 پشتهٔ فنی

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · shadcn/ui · framer-motion · WebGL خام

## 🚀 اجرای محلی

```bash
bun install
bun run dev        # http://localhost:3000
```

## 📦 بیلد استاتیک

```bash
STATIC_EXPORT=1 npx next build
# خروجی در پوشهٔ out/
```

انتشار روی GitHub Pages با push به `main` به‌صورت خودکار انجام می‌شود
(`.github/workflows/deploy.yml`).

## 🗂 ساختار

```
src/
├─ app/                  # صفحه، چیدمان، سیستم طراحی (globals.css)
├─ components/hesabyar/  # کامپوننت‌های اپ (فرم، لیست، آمار، نمودار، افکت‌ها)
├─ components/ui/        # اجزای پایهٔ shadcn/ui
└─ lib/                  # منطق مالی و فروشگاه localStorage
```

## 🔒 حریم خصوصی

بدون حساب کاربری، بدون کوکی ردیابی، بدون سرور. برای پاک‌سازی کامل، از دکمهٔ «پاک کردن همهٔ داده‌ها» در پایین صفحه استفاده کنید.
